# contents

- titles.md: The movie titles in the WebFlyx collection
- classics.csv: A comma-separated list of classic movies (title, director, year, genre)
- guilty_pleasures.md: Secret favourites (tell no one)
- genres/: Genre index — one file per genre, each listing its movies
- ratings.md: Leaderboard of all classics ranked by personal rating (out of 10)
- quotes: A directory of files containing memorable quotes from movies
